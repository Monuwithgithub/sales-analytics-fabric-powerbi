# 🚀 Microsoft Fabric App

The completed Sales Analytics Power BI report was published as a Microsoft Fabric App.

## App Features

- Provides access to the published Sales Analytics report.
- Allows users to interact with the Power BI dashboard.
- Provides an organized end-user consumption experience.
- Uses the customized visual theme created for the project.
